# Dumbledore AI — RAG-чат по вселенной Гарри Поттера

AI-агент который отвечает на вопросы по лору Гарри Поттера в роли Дамблдора.

## Что умеет
- RAG — отвечает только на основе базы лора, не галлюцинирует
- Память — помнит историю разговора
- Характер — говорит как Дамблдор: мудро и загадочно

## Живое демо
https://huggingface.co/spaces/sabinabay/dumbledore-ai

## Технологии
- Python, Groq API, ChromaDB, Sentence Transformers, Gradio
