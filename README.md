# hogwarts-oracle — RAG-система по вселенной Гарри Поттера

AI-агент который отвечает на вопросы по лору Гарри Поттера 
и играет роль NPC с долгосрочной памятью.

## Что умеет

- RAG — ищет ответы только в базе лора, не галлюцинирует
- NPC Дамблдор — помнит историю разговора через summarization
- Eval pipeline — автоматическая проверка качества ответов

## Результаты eval

4/4 тестов прошло:
- Сколько хоркруксов? ✅
- Где учится Гарри? ✅  
- Кто убил Дамблдора? ✅
- Что такое квиддич? ✅

## Технологии

- Python
- Groq API (LLM)
- ChromaDB (векторная база данных)
- Sentence Transformers (embeddings)

## Как запустить

1. `pip install groq chromadb sentence-transformers`
2. Добавь GROQ_API_KEY
3. Запусти `app.py`
